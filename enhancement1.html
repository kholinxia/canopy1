Enhancements beyond the base requirements

Four HTML/CSS enhancements were added on top of the core assignment requirements, all implemented with pure CSS and no JavaScript. Each one is described below along with a link to where it can be seen in action on the live site.

1. Button / link hover effect

Every link in the main navigation menu and every button on the Contribute and Enquiry forms uses CSS transition and transform properties (see the .menu a and button rules in styles/style.css), so hovering smoothly animates colour and position instead of changing instantly.

Reference: MDN Web Docs – the CSS transition property.

2. CSS-only hamburger navigation

On wide screens the full menu is always visible across the top of the page. On phones and other narrow screens (700px and below) it collapses behind a Menu button (☰) at the top left, next to the logo, and opens as a panel listing every page. This is built with the "checkbox hack": a hidden <input type="checkbox"> paired with a <label>, and a CSS general sibling selector (.nav-toggle:checked ~ .menu in styles/mobile.css) that reveals the menu when the checkbox is checked — no JavaScript involved.

The slide-down dropdown under Explore uses a max-height + transition in styles/style.css (.has-dropdown.open .dropdown). In Assignment 1 this opened with :hover. In Assignment 2 it is opened by JavaScript, so it is explained on the Enhancements 2 page. On narrow screens, where hover isn't reliable with touch, styles/mobile.css shows the same links already nested under Explore.

Reference(s): CSS-Tricks – "The Checkbox Hack", W3Schools – "How To Create a Dropdown Navbar".

3. Photo gallery

The species gallery on the Species page lays out thumbnails of all eight tracked species in a responsive grid. Hovering (or focusing, for keyboard users) a thumbnail zooms the photo in smoothly via transform: scale() on the image inside an overflow: hidden container (see .gallery-item in styles/style.css), and each thumbnail links straight to that species' full profile further down the page.

Reference: MDN Web Docs – the CSS object-fit property.

4. Flip cards

The quick-reference cards on the Species page use 3D CSS transforms (perspective, transform-style: preserve-3d and backface-visibility: hidden in the .flip-card rules) so that hovering or focusing a card flips it over to reveal one key fact about that species on the back, without any JavaScript.

Reference: W3Schools – "How To Create a Flip Card".

Why these enhancements

Each enhancement was chosen because it directly improves how a real contributor browses and uses the site — a friendlier mobile menu, a faster way to preview species, and a fun way to surface one extra fact per species — rather than being purely decorative.
