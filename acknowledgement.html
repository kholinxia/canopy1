Third-party code

No library, framework or copied script is used. The only third-party parts are two online services. Web3Forms receives the form data and emails it to me (its access key is a public key made for use in page code). Pl@ntNet identifies plants from photos on the Contribute and Identify pages; its API key is my own free-plan key.
